# 5-Minuten-Übung: Ein Neuron von Hand berechnen

Ein Neuron erhält die Eingaben `x1` und `x2`. Es berechnet zunächst die gewichtete Summe:

`z = x1 * w1 + x2 * w2 + b`

Die Ausgabe lautet:

- Wenn `z >= 0`, gibt das Neuron **1** aus.
- Wenn `z < 0`, gibt das Neuron **0** aus.

Gegeben sind die Gewichte `w1 = 0,5`, `w2 = -1` und zunächst der Bias `b = 0,25`.

## Aufgaben

1. Berechnet die Ausgabe für `x1 = 2` und `x2 = 1`.
2. Berechnet die Ausgabe für `x1 = 1` und `x2 = 2`.
3. Ändert im zweiten Fall den Bias auf `b = 1,5`. Was passiert mit der Ausgabe?
